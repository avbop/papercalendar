# Assets
The script relies on the following files in the directory set by `-a`/`--assets` (which is `assets` by default).

## Icons
The icon files should be in a square aspect ratio and should have the following names.

    assets/
        birthday.jpg
        generic.jpg
        missal.jpg
        op.jpg
        prayer.jpg
        wedding.jpg

## Fonts
The font files should have the following names.

    assets/
        bold.ttf
        regular.ttf

A recommended font is [Charis](https://software.sil.org/charis/), as it works well in print and supports a large character set.[^bpt]


[^bpt]: [Butterick's Practical Typography](https://practicaltypography.com/charter.html).
